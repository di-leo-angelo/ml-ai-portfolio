# Projects

Create one directory per portfolio project, using a short kebab-case name:

```text
projects/
└── example-project/
    ├── README.md
    ├── notebooks/
    ├── src/
    └── tests/
```

A project README should cover:

1. The problem and why it matters
2. The dataset, source, and usage terms
3. The methodology and evaluation metric
4. The main results and visualizations
5. Limitations and possible improvements
6. Exact reproduction instructions

Do not commit private data, credentials, generated models, or large datasets.
